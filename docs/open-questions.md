# Неизвестные и решения следующих этапов
1. Полный Xcode отсутствует; все четыре SDK неполны (нет CoreFoundation/CFBase.h), XCTest недоступен; требуется установка версии с Swift 6 и SDK macOS 15+. Не скачиваем многогигабайтный пакет молча. Это текущий внешний gate.
2. Реальный STT/LLM endpoint/model/retention не выбраны. Fake по умолчанию, никаких платных вызовов.
3. GRDB release и зависимости проверяются при внедрении persistence; миграции и схема заранее определены.
4. TCC allow/deny/revoke и audio routing на реальных устройствах ещё не проверены; не запрашивать при запуске.
5. Screen exclusion, full screen, multi-display и сторонние share paths неизвестны до Phase 2 tests.
6. Подтверждённые факты резюме отсутствуют. Перечень технологий/Rapid из ТЗ — неподтверждённые кандидаты, HR не использует их как опыт.
7. Model size/license/CPU/RAM измеряются до согласованной загрузки; 8 GB RAM требует ограниченных buffers.
8. Apple Developer ID отсутствует в контексте; не проверяем приватные identities. Ad-hoc dev достаточен; notarization позднее.
9. Официальный job API/scopes/rules неизвестны; интеграция не выбирается по предположению.
