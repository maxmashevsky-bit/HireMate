# Приватность и хранение

Ниже описана политика текущего исходного кода. Runtime и отсутствие утечек ещё не подтверждены проверками.

| Данные | Место и срок | Отправка |
|---|---|---|
| Тема/профиль/onboarding/геометрия/параметры API/быстрые действия | UserDefaults до изменения/сброса | Автоматической отправки нет; инструкция действия включается в запрос по команде |
| API key | macOS Keychain, несинхронизируемый item | Только Authorization выбранного API; не БД/логи/export |
| Профили и подтверждённые факты | SQLite до изменения | Активный профиль включается в AI-запрос после согласия |
| Разговор без сохранения | Память до смены встречи/профиля или завершения | Только ограниченная история текущего подчата по команде |
| Сохраняемая встреча | SQLite до удаления | Экспорт JSON по кнопке; ограниченная история в AI по команде |
| Аудио | Bounded PCM ring и максимум 6 фрагментов по 60 с в памяти | Выбранный сегмент — только после согласия и «Распознать»; audio file не создаётся |
| Снимок | Память: preview → обрезка/redaction → один запрос; на диск не пишется | Просмотренные конечные bytes, явно приложенные к вопросу; только vision-enabled model |
| Заметки/chunks/FTS | SQLite до удаления, source path/hash локально | Только AI-разрешённые неархивные заметки активного профиля и включённый поиск контекста; source path не входит в prompt |
| TTS | Текст в системном синтезаторе на время чтения | Установленные системные голоса; отдельного API отправки нет |
| OSLog | Системная ротация | Тип события, размер, status; без текста, ключа, аудио и image bytes |

Telemetry отсутствует. Демо не использует сеть. Согласие на TCC не разрешает автоматический upload. При изменении конфигурации провайдера сбрасываются согласия и отменяются текущие запросы. Смена профиля отменяет генерацию/распознавание, очищает снимок и останавливает захват звука.

В собственный API могут уйти вопрос, активные подтверждённые факты, история текущего подчата, разрешённые заметки и просмотренное вложение. Политика хранения сервера неизвестна до выбора провайдера. Отмена локального запроса не удаляет уже принятые сервером данные. Ключ в памяти сетевого запроса необходим для авторизации; приложение не записывает его на диск вне Keychain.

Чёрная redaction применяется к пикселям до кодирования. JPEG может содержать артефакты; выбранная зона расширяется на несколько пикселей. Предпросмотр показывает закодированные bytes. Полное исходное изображение после изменения не удерживается моделью редактора, но приложение не обещает криптографическое стирание RAM или системного swap.

Удаление встреч/заметок выполняется транзакционно с удалением дочерних записей. SQLite secure_delete включён; это не обещание удаления копий из Time Machine, APFS snapshots, экспорта или серверов. Полный Privacy Center, reset/backup/restore ещё не реализован. Явный экспорт может содержать персональные тексты — путь выбирает пользователь.

Системное озвучивание может попасть в system audio capture. В приложении есть отдельное предупреждение, play/pause/stop и выключенное по умолчанию auto-read. Собственного выбора output device нет.
