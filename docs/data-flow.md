# Потоки данных

Текущий исходный код: пользователь → UI → application models → domain/protocols → platform adapters. Все описанные новые потоки пока не проверены runtime.

1. Mic AVAudioEngine / system ScreenCaptureKit → раздельные mono PCM frames → AVAudioConverter 16k → actor/ring/VAD → фрагмент в памяти. Сегменты автоматически не отправляются и не записываются в файл.
2. Выбор фрагмента + согласие + кнопка → Fake STT либо WAV multipart → безопасный NetworkClient → свой API → редактируемая расшифровка. Кнопка «Использовать как вопрос» только переносит текст.
3. Вопрос → активный профиль → локальный поиск разрешённых заметок → ограниченный контекст текущего подчата → текст + просмотренный снимок + инструкция выбранного действия → Fake/SSE provider → UI → память или выбранная SQLite-история. Бюджет исключает старые сообщения/непоместившиеся фрагменты с индикатором.
4. Явный screenshot → выбранный display/window → память → PNG/JPEG preview → crop/redaction → отдельное подтверждение → одно вложение. Никаких автоматических снимков и screenshot temp files.
5. Импорт UTF-8 TXT/Markdown → размер/формат → preview/source hash → черновик → сохранение транзакцией → notes/chunks/FTS5. Поиск локальный. Каждый note имеет AI opt-in, выключенный по умолчанию; профиль отдельно включает retrieval.
6. Завершённый ответ → TTS только по play или auto-read opt-in → установленный системный голос/аудиовыход. Захват системного звука может включить это озвучивание.

Keychain отделён от сериализуемой конфигурации. NetworkClient использует ephemeral URLSession без cookie/cache persistence, не следует redirects, ограничивает ответ и не журналирует содержимое. Реальная совместимость TLS/HTTP/streaming/cancellation требует тестов. Новые сетевые запросы не выполнялись во время разработки.

Trust boundaries: TCC, процесс, учётная запись macOS, Keychain, SQLite, пользовательский файл, endpoint. Импортированные документы и AI-ответы не исполняются как команды. RAG-фрагменты обрамляются как справочные данные; это не доказательство полной защиты от prompt injection. Локальный путь исходной заметки не добавляется в AI-контекст.

Будущие потоки: запись AVAssetWriter, embeddings, mock/analysis, resume/vacancy — ещё не подключены.
