# Max Interview Copilot

Личное нативное приложение Максима Машевского для подготовки к Go-интервью и разрешённых встреч. Русский интерфейс, macOS 15+, Apple Silicon, без обязательного сервера.

Проект находится в активной разработке. Доступны нативный интерфейс, демонстрационный режим без сети, раздельный захват микрофона и системного звука, ручное и пакетное распознавание фрагментов, потоковые ответы, локальная история, заметки, снимки экрана и компактное overlay-окно. Mic/system/combined capture проверены на целевом Mac; внешние провайдеры и длительная нагрузка требуют отдельной настройки и проверки.

Главный источник требований и визуальных референсов — `docs/source/Codex_App_Final.docx`. Прежний TXT-промпт удалён и больше не используется.

## Сценарии в коде

- Демо без ключа и сети: фиксированные учебные ответы и расшифровки, без анализа введённого текста или изображения.
- Полный локальный демо-путь связывает аудиобуфер, завершённый фрагмент, очередь STT, предложенный вопрос и потоковый учебный ответ; разрешения macOS и внешний API для него не нужны.
- Три независимых профиля: Go Live Coding, Go Техвопросы, Go HR. Факты опыта заполняет и подтверждает пользователь.
- Встречи и поддиалоги: история в памяти по умолчанию, явный выбор сохранения в SQLite, переименование, реальные счётчики, поиск по названию, экспорт JSON/Markdown и удаление.
- Активное окно диалога ограничено последними 200 сообщениями и 1 000 000 символов; в памяти одновременно кэшируется не более восьми поддиалогов. Полный текст сохраняемой встречи остаётся в SQLite и входит в экспорт.
- Звук: отдельный запуск mic/system/combined capture, буфер, ручная и явно включаемая автоматическая очередь распознавания с раздельными результатами источников. На целевом Mac подтверждены уровни, рост обоих буферов, создание ручного фрагмента и штатная остановка. В онбординге есть трёхсекундная локальная проверка микрофона с живым индикатором, без записи на диск и сети.
- Локальная эвристика предлагает законченный вопрос из финальной расшифровки системного звука; отправка в AI остаётся ручным действием.
- Настройки источника, выделения вопроса и аудиобуфера переживают перезапуск; согласие участников и запуск захвата остаются ручными.
- Последняя операция STT показывает локальные задержки очереди, первого события и полного запроса без записи аудио или текста в метрики.
- Пять сохраняемых модельных слотов текущего BYO API позволяют менять модель и бюджеты, не меняя endpoint, ключ и STT. Цикл доступен кнопкой и отдельно включаемой горячей клавишей; автоматического каталога моделей нет.
- Общий локальный поиск работает во встречах, вакансиях, встроенных контекстах и заметках. Заметки ищутся по заголовку и тексту в пределах активного профиля без AI-запроса.
- Ограниченная хронология финальных реплик хранит собеседника и кандидата раздельно: в памяти для эфемерной встречи, в SQLite для сохраняемой. Последние 50 реплик/12 000 символов и короткая дословная выжимка восстанавливаются без запуска захвата, сетевого согласия или AI opt-in и входят в текстовый экспорт.
- По явному включению до 4 000 символов недавней хронологии добавляются в ограниченный AI-контекст как недоверенные данные.
- Собственный OpenAI-compatible API: URL/модели в настройках, ключ только Keychain, согласие на отправку, отменяемый stream.
- Последний LLM-запрос показывает локальное время до первого токена и полного завершения; STT/LLM метрики также доступны раздельно в «Диагностике» и очищаются вручную.
- Один потоковый ответ ограничен 256 000 символов; превышение безопасно останавливает запрос и оставляет полученную часть в истории со статусом незавершённого ответа.
- Ручной тест в «Диагностике» выполняет 20 чтений SQLite и показывает минимум, p95 и максимум без вывода содержимого записей.
- Снимок: явный capture, preview, обрезка/закрашивание и одно вложение к вопросу. Изображение не сохраняется на диск. Полный снимок и одноразовое вложение к следующему вопросу проверены в запущенном приложении.
- Пять быстрых действий с отдельными профилями и системное TTS, выключенное по умолчанию. Ручной запуск и немедленная остановка TTS проверены в интерфейсе.
- «Диагностика» показывает фактическое состояние рабочего overlay-окна, click-through, непрозрачность, результат регистрации и последнюю реально полученную глобальную команду; оттуда можно показать окно, вернуть ввод или вернуть клики без перезапуска.
- Ручной Compatibility Test делает контрольный и защищённый снимки через ScreenCaptureKit и сообщает, попало ли overlay-окно в захват на текущем Mac. Это фактическая проверка одного пути захвата, без обещания невидимости в сторонних программах.
- В настройках рабочего окна можно переназначить клавишу и Shift для каждой из 33 глобальных команд. Новое сочетание применяется сразу, конфликт регистрации показывается рядом, а отдельная кнопка возвращает команду к безопасному значению по умолчанию.
- Непрозрачность и положение рабочего окна сохраняются локально. Координаты из другого Space или изменённой конфигурации дисплеев ограничиваются видимой областью, чтобы окно не восстановилось за краем экрана.
- В popover рабочего окна есть кнопки сдвига и изменения ширины/высоты; они дают запасной способ управления без глобальных сочетаний и сохраняют новый frame.
- Трекер: локальные карточки/этапы/переходы/архив, среднее время завершённых этапов и сравнение двух подходящих карточек с фильтром этапа. Связь со встречами, PDF и Telegram ещё не реализованы.
- Заметки: Markdown toolbar с selection/Undo/Redo, таблицами/списками/цитатами и code preview, импорт, теги и локальный FTS. Библиотека загружается страницами с настоящими счётчиками и фильтром папок; блокнот встречи ищет независимо в той же БД. Сохранённые fragments доступны в inspector с явным пересозданием индекса. В AI попадают только разрешённые заметки активного профиля при включённой настройке контекста.

Это перечень исходников, не обещание пройденных acceptance checks. Не реализованные расширенные разделы обозначены в интерфейсе.

## Проект и сборка

`MaxInterviewCopilot.xcodeproj` содержит приложение и XCTest target. Код написан на Swift 6 для macOS 15+. SQLite работает через GRDB 7.11.1; текст лицензии зависимости находится в `Resources/Licenses`.

Сборка и проверки:

```sh
./scripts/build.sh
./scripts/test.sh
./scripts/verify.sh
```

Второй вариант локальной сборки — `./scripts/build.sh --spm`. Проверка разрешений микрофона и записи экрана выполняется вручную на целевом Mac. Инструкция: [release](docs/release.md).

## Управление окном

Безопасный набор по умолчанию использует ⌘⌥, потому что одиночные системные сочетания macOS конфликтуют с Hide, New и другими командами. Доступны: B — показать/скрыть; W — click-through; D — ввод; G — отмена ответа и TTS; [ / ] — прозрачность; стрелки — перемещение; ⇧стрелки — размер; 1–5 — быстрые действия; H / ⇧H — полный снимок / подготовка области; N — заметки; Return / ⇧Return — отправка со снимком / без него; ⇧K/L — предыдущий/следующий поддиалог; P / ⇧P — новый поддиалог / полоса поддиалогов; ⇧X — сброс текущего контекста; R — звук; ⇧A — режим вопросов по паузам. Для прокрутки ответа к набору добавляется третий модификатор.

Можно выбрать основу ⌃⌥ или полностью отключить глобальные сочетания. На целевом Mac текущая сборка зарегистрировала 33 сочетания без конфликта. Проверка их внешнего срабатывания, Spaces и нескольких дисплеев ещё не завершена.
